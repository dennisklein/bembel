Design record

bembel

Hold the address space. Pour out addresses, names and networks.

bembel is the source of truth for IP addresses, DNS and DHCP of a research and HPC organisation. It replaces OpenNetAdmin. It is API first: the web UI, the CLI, the OpenStack and Kubernetes integrations and the export agents use only the public REST API. Access control uses OIDC with roles and scopes. bembel models IPv4 and IPv6, VRFs, Ethernet, RoCEv2 and InfiniBand. It exports BIND zones, dhcpd.conf and OpenSM partitions, and shows the racks from FNT Command.

Key decisions

The twelve decisions that shape the design. Each card links to the chapter that specifies it.

  1. Build, not adopt: NetBox is strong on the generic parts and weak on fabrics, DNS, DHCP, assets and the ONA migration, which are the daily work here.Why a new tool
  2. Go, PostgreSQL 18, SvelteKit: one binary with an embedded static UI, one language for the server, the CLI and the Kubernetes parts.Architecture and stack
  3. Spec first: api/openapi.yaml is the reviewed contract, and all clients are generated from it.API first
  4. The database enforces the model: unique addresses per VRF, no overlapping siblings, typed links, history for each row.Core model
  5. Derive, do not copy: A, AAAA and PTR records, reverse zones and DHCP reservations follow from addresses and interfaces.DNS in the model
  6. Fabrics are first class: Ethernet, RoCEv2 with QoS profiles and rails, InfiniBand with partitions and port GUIDs.Fabrics
  7. Scoped bindings: a role in a VRF, a prefix subtree, a zone subtree, a site, a team or a tag. Dangerous changes need a second person.Access control
  8. Export to the servers we have: BIND and ISC dhcpd stay. Agents pull signed bundles, check them and reload.DNS export
  9. No flag day: import ONA, diff the exports of both tools each night, switch over after 14 clean nights.Migration
  10. FNT Command stays the DCIM: bembel mirrors racks and devices read-only and links hosts to them.Assets
  11. A local assistant that cannot change data: it reads with the permissions of the user and proposes drafts that the user applies.Assistant
  12. Stateless and observable: three replicas in Kubernetes, CloudNativePG, Prometheus metrics, JSON logs for Loki.Operations
