Open questions and sources

This chapter lists what bembel does not do, the points of the design that are not decided, and the sources of the research.

  • bembel holds values and exports them. It does not configure devices and does not serve DNS or DHCP itself.
  • Each open question names the part of the design that its answer changes.
  • The sources list the pages that the research read. A fact from a search snippet is marked.

Out of scope

Not in bembelWhy
A CNI IPAM pluginThe latency and availability needs at pod start do not fit a central service (Kubernetes).
Write back to FNT CommandFNT is the source of truth for the assets. bembel mirrors it read only (Assets).
A DHCP server or a DNS server inside bembelbembel builds files and bundles. BIND, dhcpd and Kea serve them (DNS, DHCP).
A firewall or router config managerbembel gives values and feeds. The network automation writes the config (Routing).

Open questions

These points are not decided. The answer changes the design only where the table says so.

QuestionState and effectAffects
Name. Is bembel final?Chosen after a search of crates.io, npm, PyPI and GitHub on 2026-11-04. The fallback is glebe. Trademark databases and the Go module path are not checked. A rename costs a day now and a lot after the first release.Go module path, packages
VPN session retention.The design keeps VPN sessions for 90 days. The data protection officer of the site must agree to the value and to the group that may read sessions. A shorter value is a config change.VPN sessions
ExtremeCloud IQ API.Only GET /clients/active is confirmed. The device and location paths, the paging and the rate limit need a test against the site tenant with an API token.XIQ mirror
FNT attribute names.The entity names for rack, device, port and cable, the login call, the paging parameters and the delta timestamp are not public. An FNT admin must give a Swagger or OpenAPI export of the tenant. Until then the mapping table is a plan.FNT sync
ISC dhcpd end of life.ISC has ended the development of ISC DHCP (since 2022). bembel exports dhcpd because ONA does and because the parallel run needs the same format. It also exports Kea. When does the organisation move its servers to Kea? The answer sets the end of the dhcpd export.DHCP export
LLM model choice.The examples use gpt-oss-20b or qwen3-coder-30b for chat and bge-m3 or nomic-embed-text for embeddings, on llm.example.org. The choice depends on the GPU of the host, the quality of tool calls and the language of the users. An evaluation set of 50 questions about the story data decides. Embedding model changes need a full re-embed.Assistant
NetBox exchange need.No team uses NetBox today. If a partner site or a tool (a NetBox-based automation) needs the model, bembel builds the exchange. If not, it stays out.NetBox exchange
IPv6 SLAAC policy.bembel only observes SLAAC and EUI-64 addresses. Open: how long does an observed address stay after the last report, does it count in utilisation, and does a privacy address (RFC 8981) create a host entry? The default proposal: keep for 30 days, count by the number, ignore privacy addresses.Observed addresses, utilisation
Level trigger.The exclusion constraint on prefixes uses a computed level (Allocation). The trigger and its cost on 105 prefixes need a prototype.Prefix constraints
pgvector in CloudNativePG.How the extension gets into the image (own image, or an extension image volume) depends on the operator version. Verify on the target cluster. The first production cluster already needs it.Database image
Rack numbering.Does FNT number U from the bottom or the top for each rack, and does it differ by rack? The model has a field per rack. Verify with the tenant export.Rack view

Sources

The design rests on research notes made on 2026-11-04. Some sources could not be reached from the research environment (for example the FNT customer portal and parts of postgresql.org). The notes mark such facts, and this record keeps the marks. Where a statement says "to verify", the source is a search result or prior knowledge, not a fetched page.
