The zone is sound. Three points need a look before the next export.

  1. The TXT of motd has 263 bytes. A string in a zone file can have 255 bytes at most. ONA writes one string. bembel splits the text into 2 strings, also in compat mode. This is the known difference KD-002. The semicolon in the apex TXT is not escaped; both sides write it the same.
  2. The SRV target ldap2.example.org has no A record in view external. The SRV is internal only, so no client sees the gap.
  3. cn-011 is new. a.berger added it in ONA at 16:12, and import imp-20261104-1612 brought the A record and the PTR. The parallel run compares one dump on both sides, so it shows no line for it.
