CLI

The CLI bembel is the same binary as the server. This chapter lists its commands, flags and exit codes, and shows terminal examples.

Commands

The CLI is the same binary as the server. It is a thin shell over the generated Go client. It adds output formats, the device login, shell completion and the help system (help). Global flags: --server, -o table|json|yaml|name, --no-color, --idempotency-key. Settings come from ~/.config/bembel/cli.yaml, then BEMBEL_SERVER and BEMBEL_TOKEN.

CommandDoes
bembel login / logout / whoamiDevice login, forget tokens, show /v1/me
bembel prefix ls|show|create|edit|rm|freePrefixes. ls --vrf --within --depth --contains --status --tag
bembel prefix allocate PARENT --length N --name NAMEChild prefix from a pool
bembel address ls|show|allocate|confirm|renew|release|editAddresses and claims. allocate --prefix CIDR --name FQDN --mac MAC --reservation; --claim-ttl 10m makes a claim; ls --status claimed lists the claims
bembel host ls|show|create|edit|rmHosts and interfaces. --kind vm --runs-on hv-03 (--kind sets host_kind)
bembel zone ls|show|create|rmZones. rm opens a change request
bembel record ls|add|edit|rm ZONEManual records. add ZONE ssh CNAME login --ttl 300
bembel export bind|dhcpd|opensm|prefix-list|address-group|eduvpnBuild or fetch an export. See below.
bembel apply -f FILERead a CSV or YAML file, show the plan, apply after a confirm (plan and apply). --yes skips the question, --plan-only stops after the plan.
bembel address move, bembel interface move, bembel prefix renumber|resize|splitMoves (renumber). renumber waits for --confirm OPERATION before phase 2.
bembel record enable|disable ZONE NAME TYPETurn a manual record on or off without a delete
bembel note add|ls|rmNotes. add host/cn-004 --level warn --pin "PSU 2 failed, ticket 8812"
bembel observe import --format nmap-xml FILESend an nmap scan as observations
bembel vni allocate|lsVNIs from a VNI range
bembel vpn profile ls|show, bembel vpn session ls --address IP --at TIMEVPN profiles and the session lookup (sessions)
bembel report NAMEPrint a report as a table or CSV
bembel admin break-glass --user NAME --reason TEXTEmergency session when the IdP is down. Runs only on a server host (break-glass).
bembel import ona|netboxImport from a MariaDB dump, an ONA API or a NetBox API. --dry-run makes findings only.
bembel sync fntStart and watch an FNT sync
bembel vm prepareClaim the addresses with publish: true (DNS, DHCP) and print cloud-init network config
bembel access check [--explain] [--as SUBJECT] PERMISSION KIND/IDCheck a permission and explain it (POST /v1/me/permissions:check)
bembel binding ls|create|delete, bembel token ls|create|revokeManage bindings and tokens
bembel change ls|show|approve|reject|withdrawChange requests
bembel events tailFollow the SSE stream
bembel api METHOD PATH [-d JSON]Raw call with auth, like gh api
bembel help [TOPIC]Help topics (same text as the UI help pane)
bembel mcpMCP server for agents, over stdio or HTTP
bembel serveRun the server: API, UI, workers (deployment)
bembel migrate up|down|statusDatabase migrations (goose, embedded)

Exit codes: 0 ok, 1 error from the server, 2 usage, 3 not found, 4 denied, 5 held for approval (the change request id is printed).
